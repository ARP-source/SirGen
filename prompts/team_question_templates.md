# Sentinel-OR team question templates (filled by code, never by a model)

The orchestrator fills these after round 2. Nothing here is generated by an LLM: categories come from the validated round-2 AgentMessages, and every evidence phrase is built from the loaded data record behind a cited `source_id`. The screen shows the source_ids next to the question.

## 1. Outcome (SPEC rule)
Use the three round-2 categories. An agent that is unavailable (timeout or failed validation twice) counts as `unclear`.
- **converged**: all three categories are the same, or two are the same (not `unclear`) and the third is `unclear`. The shared category is the one they share.
- **split**: anything else.

## 2. Ranking categories (split only)
Ignore `unclear`. Rank the remaining categories by: number of agents (more first), then summed confidence (high 3, medium 2, low 1), then the fixed order `bleeding_concern`, `drug_effect`, `artifact`, `no_concern`. A = first, B = second (may be absent).

## 3. Evidence phrases `{ev_X}`
For category X: take the agents in X, ordered by confidence (high first; ties surgical, anesthesia, record). Take their cited source_ids round-robin (each agent's first, then each agent's second, ...), skip duplicates, stop at 3 phrases. Join with "; ". Build each phrase from the data record, not from the model's note. `n` is the absolute value of `rel_alert_s`.

| source_id | phrase |
|---|---|
| `phase` | "phase: {display, lowercase}" |
| `tools` | "{tools with ≥ 3 s in the window, lowercase, joined with 'and'} in view" |
| `surg-NN` | "{event text up to the first ';', parentheses removed, lowercase first letter}, from {n} s before the alert" ("at the alert" if 0; "{n} s after the alert" if positive) |
| `oop-N` | "{event, lowercase first letter}" |
| `omni-*` | "video review of the last 10 s" |
| `drug-NN` | t_s known: "{drug} {increase / decrease / bolus / change, the first word found in detail} {n} s before the alert"; t_s null: "{drug} running" |
| `vit-art`, map_drop | "MAP {first} to {now} and HR {first} to {now} over the last {span} s" (first = sample at max(alert − 60 s, segment start)) |
| `vit-art`, art_spike | "arterial SBP peak {max}, back near baseline within {k} s" (k = s from alert until SBP is within 10 mmHg of its pre-alert value) |
| `vit-nibp-NN` | "cuff {sbp}/{dbp}, {n} s {before/after} the alert" |
| `meds-NN` | "{drug} last dose about {last_dose_h_before_incision} h before incision" (if that field is missing: "{drug} on the chart") |
| `lab-NN` | "{test without '(pre-op)'} {value} {unit}" |
| `hx-NN` | "{condition, lowercase first letter}" |
| `enc-NN` | "{field with '_' as space}: {value, lowercase first letter}" |
| `note-NN`, `alg-NN` | "{type}" / "{substance} intolerance" |

## 4. Templates
Labels: `bleeding_concern` "possible bleeding", `drug_effect` "drug effect", `artifact` "possible measurement artifact", `no_concern` "no concern".
Checks: `bleeding_concern` "Check the field for bleeding", `drug_effect` "confirm the drug timing", `artifact` "check whether the arterial line was just flushed or sampled", `no_concern` "confirm the reading".

**Converged** (summary, then team_question):
- `bleeding_concern`: "The sources agree this fits possible bleeding ({ev})." / "Is bleeding visible in the field?"
- `drug_effect`: "The sources agree this fits a drug effect ({ev})." / "Does the drug timing match what the anaesthesia team sees, and is the field unchanged?"
- `artifact`: "Likely artifact ({ev})." / "Was the arterial line just flushed or sampled?" (artifact events stay a quiet flag: no banner)
- `no_concern`: "The sources see nothing that needs attention ({ev})." / "Does the reading match what the team sees?"
- `unclear` (all three unclear): "The sources do not explain this change." / "What does the team see in the field and on the monitor?"

**Split**:
- A and B: "Two explanations fit: {label_A} ({ev_A}) and {label_B} ({ev_B}). {Check_A} and {check_B}."
- A only (the others unclear): "One source suggests {label_A} ({ev_A}); the others cannot explain the change. {Check_A}."
- A third named category is not in the question; it stays visible in its agent column.
